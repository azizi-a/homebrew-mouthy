# homebrew-mouthy

Homebrew tap for [Mouthy](https://github.com/azizi-a/mouthy), which reads selected text aloud with an offline Kokoro voice. Apple Silicon, macOS 13.4 or later.

```bash
brew install --cask azizi-a/mouthy/mouthy
```

Mouthy is not notarised; the cask's caveats explain how to allow its first launch.
